# Contributing to AIOS

1. Keep AIOS local-first and preserve the confirmation boundary for every mutation or external action.
2. Do not commit credentials, databases, model files, service data, conversations, caches, or generated reports.
3. Add focused tests for behavior changes and run Ruff before opening a pull request.
4. Build Studio when changing `dashboard-web/`.
5. Keep documentation concise and update only durable, user-facing operational information.
